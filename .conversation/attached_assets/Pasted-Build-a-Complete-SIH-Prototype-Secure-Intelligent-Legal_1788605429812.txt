Build a Complete SIH Prototype: Secure Intelligent Legal & Police Document Management System

Build a polished, fully functional web-based prototype for a Smart India Hackathon project titled:

“Secure Intelligent Digital Document Management System for Legal & Investigative Records”

1. PROJECT OBJECTIVE

Create a secure, case-centric document management platform for police officers, forensic officers, prosecution/legal officers and administrators.

The prototype should demonstrate how sensitive legal and investigative documents can be:

- securely stored
- organized by case
- searched quickly
- classified using AI
- converted to searchable text using OCR
- protected using cryptographic hashing
- digitally signed
- version controlled
- tracked through a complete audit trail
- checked for tampering
- accessed according to user roles and permissions

This is a prototype/demo, not a production police or court system.

Do NOT claim integration with real government systems.

Use realistic mock/demo data.

---

2. TECHNOLOGY

Prefer:

- Frontend: React + TypeScript
- Styling: Tailwind CSS
- Backend: Node.js + Express OR the simplest reliable backend available in Replit
- Database: PostgreSQL if easily available; otherwise SQLite for prototype
- File storage: local storage for demo, structured so it can later be replaced by S3/MinIO
- Icons: Lucide React
- Charts: Recharts if useful

Keep the architecture modular so components can later be replaced with production services.

The application must run successfully in Replit with one clear Run command.
